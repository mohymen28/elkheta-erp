# 🏢 منظومة الخطة - نظام إدارة الموارد والمشتريات (Custom ERP)

نظام متكامل ومخصص لإدارة المشتريات، المخازن، الصيانة، وسلسلة الموافقات والرقابة المالية.

---

## 🚀 تشغيل النظام (Quick Start)

### 1. تشغيل الواجهة الخلفية (Backend)
```bash
cd backend
npm install
npm run db:push
npm run db:seed
npm run dev
```
- سيرفر الـ API سيعمل على: `http://localhost:5000/api`

### 2. تشغيل الواجهة الأمامية (Frontend)
```bash
cd frontend
npm install
npm run dev
```
- تطبيق الويب سيعمل على: `http://localhost:3000`

## 🔑 الحسابات التجريبية الجاهزة (Demo Accounts)

| الدور الوظيفي | البريد الإلكتروني | كلمة المرور | الصلاحيات والمهام |
|---|---|---|---|
| **مدير النظام (Admin)** | `admin@elkheta.com` | `Admin@1234` | كامل الصلاحيات، الفروع، المستخدمين، والموافقات |
| **مدير المشتريات** | `purchase@elkheta.com` | `Purchase@1234` | اعتماد طلبات الشراء، تحويل الطلبات، إدارة الموردين |
| **مدير فرع الرياض** | `manager.riyadh@elkheta.com` | `Manager@1234` | اعتماد طلبات الفرع (الخطوة الأولى)، متابعة العمليات |
| **موظف فرع الرياض** | `employee.riyadh@elkheta.com` | `Employee@1234` | إنشاء طلبات الاحتياج ومتابعة حالتها |
| **مدير فرع جدة** | `manager.jeddah@elkheta.com` | `Manager@1234` | اعتماد وإدارة طلبات فرع جدة |

> **ملاحظة:** توجد أزرار في شاشة تسجيل الدخول تسمح لك بالدخول بنقرة واحدة بأي حساب لتجربة محاكاة سير الموافقات بين الأدوار المختلفة بسهولة وسرعة!

## 📦 محتويات المرحلة الأولى (Phase 1 Delivered):
1. **نظام المصادقة والصلاحيات (Auth & RBAC):** حماية كاملة بـ JWT وفصل الصلاحيات بين الإدارة، الفروع، والمشتريات.
2. **شجرة الفروع والأقسام (Branches & Departments):** المقر الرئيسي والفروع الإقليمية.
3. **دليل الأصناف والمواد (Product Catalog):** تصنيفات المواد، الوحدات، والحد الأدنى للمخزون.
4. **محرك مسارات الموافقات (Approval Flow Engine):** مسارات ديناميكية متعددة الخطوات قابلة للتخصيص.
5. **إدارة طلبات الاحتياج (Internal Requisitions):**
   - إنشاء طلب جديد مع إضافة بنود وحساب الإجمالي التقديري.
   - فلترة وبحث ومتابعة حالة الطلبات.
   - شاشة استعراض تفاصيل الطلب مع شريط تتبع الخطوات (Timeline Stepper).
   - شاشة مخصصة للمدراء (`Pending Approvals`) للمراجعة والاعتماد أو الرفض مع الملاحظات.
   - سجل تدقيق كامل لجميع الإجراءات (Audit Trail).
